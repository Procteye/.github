## Procteye

Proctored hiring assessments: coding tasks, written answers, multiple choice and live AI interviews, taken in the Procteye Focus desktop app with an optional phone as a second camera. Recruiters get a per-session integrity report; candidates keep a verified work history.

[Website](https://procteye.com) · [Developer docs](https://docs.procteye.com) · [Status](https://status.procteye.com)

### SDKs

Integrate proctored sessions into your own product with the Procteye API.

| Language | Package | Source |
|---|---|---|
| Go | `procteye.com/sdk-go/v2` | [sdk-go](https://github.com/Procteye/sdk-go) |
| PHP | `procteye/procteye` | [sdk-php](https://github.com/Procteye/sdk-php) |
| Node.js | `@procteye/node` | npm |
| Python | `procteye` | PyPI |
| Ruby | `procteye` | RubyGems |
| Java | `com.procteye:procteye-java` | Maven Central |
| .NET | `Procteye` | NuGet |
| Browser | `@procteye/sdk`, `@procteye/proctor-js` | npm |

Setup guides and the API reference are in the [developer docs](https://docs.procteye.com).
